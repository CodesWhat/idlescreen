# Asset provenance

The primary README and app-icon artwork, `docs/assets/idlescreen-logo.png`, is
the original idlescreen CRT product logo from the pre-publication CodesWhat
source tree. It was restored to the public repository on August 13, 2026.

The screen-saver thumbnail artwork was created for this repository by CodesWhat
on August 12, 2026. Its editable source is:

- `docs/assets/idlescreen-saver.svg`

`scripts/generate-brand-assets.sh` renders the CRT logo and screen-saver source
into their asset catalogs. The generated PNG files are distributed under the
repository's MIT License.

The menu-bar item uses Apple's `square.grid.3x3.fill` SF Symbol as a template
image at runtime. It is not redistributed as an asset.

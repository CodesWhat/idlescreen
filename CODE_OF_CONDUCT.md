# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, be constructive, and assume good faith. Harassment, personal
attacks, and abusive behavior are not tolerated in issues, pull requests, code
review, or other project spaces.

Report conduct issues privately to <security@codeswhat.com>. Reports are handled
confidentially. Maintainers may edit or remove material that violates this
standard and may temporarily or permanently restrict participation.
